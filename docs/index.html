Usage

Setup

Define the event listener before the element has been registered so the initial color-scheme-switch event is not missed.

<script> document.addEventListener('color-scheme-switch', event => { // The currently active color scheme. const colorScheme = event.target.value; // React to the active color scheme e.g. document.documentElement.style.setProperty('color-scheme', colorScheme); event.target.setAttribute('aria-label', `Switch to ${colorScheme === 'light' ? 'dark' : 'light'} color scheme`) // ... }); </script> Copy Code

Blocking rendering till the element is registered to prevent flash of inactive color scheme.

<script type="module" async blocking="render" src="https://cdn.jsdelivr.net/npm/color-scheme-switch-element/+esm"></script> Copy Code

Markup

Use the custom element.

<color-scheme-switch title="Toggle light & dark color scheme"> <!-- ... --> </color-scheme-switch> Copy Code
